## The Repository

This repository is where the Aeowun community develops the Aeowun IDE. Aeowun is a local-first engineering environment based on VS Code, substantially redesigned around a coherent engineering workflow and the MAGY agent. This source code is available under the standard [MIT license](LICENSE.txt).

## Aeowun IDE

Aeowun combines the power of a modern code editor with a deep, integrated engineering agent (MAGY). It provides comprehensive code editing, navigation, and understanding support along with lightweight debugging and a rich extensibility model.

Aeowun is built for developers who want a local-first, AI-integrated workflow that respects the "Truth" of the codebase and provides a unified engineering experience.
