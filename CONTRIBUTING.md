# Contributing to Aeowun

Welcome, and thank you for your interest in contributing to Aeowun!

Aeowun is a local-first engineering environment built on the foundation of the VS Code open-source project, but substantially evolved to prioritize agentic workflows and developer "Truth."

## Asking Questions

Have a question? Please ask on the [GitHub Discussions](https://github.com/Aeowun/AeowunV2/discussions). The active community is eager to assist you.

## Providing Feedback

Your comments and feedback are welcome. Please use the [GitHub Issues](https://github.com/Aeowun/AeowunV2/issues) page to share your thoughts, feature requests, or report problems.

## Reporting Issues

Have you identified a reproducible problem? Do you have a feature request? We want to hear about it!

### Identify Where to Report

Aeowun is developed in the [AeowunV2 repository](https://github.com/Aeowun/AeowunV2). Please file all issues there.

### Look For an Existing Issue

Before you create a new issue, please search [open issues](https://github.com/Aeowun/AeowunV2/issues) to see if it has already been filed.

### Writing Good Bug Reports

Please include the following with each issue:

* Version of Aeowun
* Your operating system
* List of extensions installed
* Reproducible steps
* Errors from the Dev Tools Console (Help > Toggle Developer Tools)

## Contributing Fixes

If you are interested in writing code to fix issues or implement features, please refer to our [Engineering Guidelines](.github/magy-instructions.md).

## Thank You

Your contributions make Aeowun possible. Thank you for your time and effort!
